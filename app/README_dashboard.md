# Urban Renewal Intelligence Dashboard

יישום Streamlit בעברית לחיפוש, סינון ובדיקה ראשונית של מתחמי התחדשות עירונית על בסיס מידע ציבורי מעובד.

Input: data/processed/urban_renewal_scored.csv

Run:

pip install -r requirements.txt

streamlit run app/urban_renewal_legal_scout.py

המידע במערכת מבוסס על מקורות מידע ציבוריים ועשוי להיות חלקי, לא מעודכן או לא מדויק. הציונים המוצגים הם אינדיקטיביים בלבד ואינם מהווים ייעוץ משפטי, תכנוני, שמאי, עסקי או נדל״ני. כל שימוש במידע מחייב בדיקה עצמאית מול המקורות הרשמיים והמסמכים התכנוניים הרלוונטיים.
