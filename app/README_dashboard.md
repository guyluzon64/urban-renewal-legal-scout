# Urban Renewal Legal Scout Dashboard

דאשבורד Streamlit בעברית לחיפוש ובדיקה ראשונית של מתחמי התחדשות עירונית מתוך קובץ Notebook 03.

Input: data/processed/urban_renewal_scored.csv

Run:

pip install streamlit pandas plotly

streamlit run app/urban_renewal_legal_scout.py

הכלי נבנה כמתנת יום הולדת לעו״ד רועי לביאב, משרד עו״ד דן הלפרט.

המידע ציבורי ואינדיקטיבי בלבד. אין לראות בו ייעוץ משפטי, תכנוני, שמאי, נדל״ני או תחזית מחייבת.
